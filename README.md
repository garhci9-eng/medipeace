# MediPeace — 의료 분쟁 트라우마 예방 웹 앱

> 환자와 의사가 **함께** 회복하는 공간

의료 분쟁은 환자만의 문제가 아닙니다. 의료진도 심각한 심리적 고통(제2피해자 증후군)을 겪습니다. MediPeace는 양측 모두의 트라우마를 줄이고, 소통과 중재를 통해 인간적인 해결을 돕는 정적 웹 앱입니다.

---

## 🌐 주요 기능

| 페이지 | 대상 | 내용 |
|--------|------|------|
| `index.html` | 전체 | 소개, 핵심 원칙, 통계 |
| `pages/patient.html` | 환자·보호자 | 단계별 행동 가이드, 환자 권리, 주의사항, 기관 연결 |
| `pages/provider.html` | 의료진 | 제2피해자 증후군 안내, 소통 가이드, 자기 돌봄 |
| `pages/mediation.html` | 전체 | 조정 vs 소송 비교, KMDIVS 절차, 협상 팁 |
| `pages/checkin.html` | 전체 | 4단계 감정 체크인 + 맞춤 다음 단계 안내 |

---

## 💡 의료 분쟁 트라우마 예방의 핵심 원칙

1. **상호 존중** — 환자도, 의료진도 각자의 고통이 있습니다
2. **열린 소통** — 진심 어린 유감 표현과 충분한 설명이 분쟁의 대부분을 해결합니다
3. **조기 개입** — 법적 절차 전 중재·조정이 모두에게 유익합니다
4. **회복과 성장** — 비난이 아닌 학습, 시스템 개선으로 이어져야 합니다

---

## 🧑‍⚕️ 제2피해자 증후군 (Second Victim Syndrome)

의료 사고에 관여된 의료진이 경험하는 심리적 고통을 말합니다.

- 연구에 따르면 **43%** 의 의사가 임상적으로 유의한 수준의 정서적 고통 경험
- 자책, 불면, 공포, 번아웃, 이직으로 이어질 수 있음
- 충분한 지지와 비징계적 사례 검토가 회복의 핵심

## 🔨 설치 및 실행

**사전 요구사항:** 없음 (순수 HTML/CSS/JS)

```bash
# 저장소 클론
git clone https://github.com/your-username/mediapeace.git
cd mediapeace

# 브라우저에서 직접 열기
open index.html

# 또는 로컬 서버로 실행 (선택)
npx serve .
# 또는
python3 -m http.server 8080
```
